Request Guidelines

  • Be specific with the movie title and year
  • Avoid duplicate requests - check existing ones first
  • Provide a compelling reason why the movie matters
  • Include director or cast information if helpful
  • Requests must be publicly available films
  • Respectful language and community standards apply
  • One request per submission
  • Voting is limited to registered users only
